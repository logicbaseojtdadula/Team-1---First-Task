# 🔄 NEW SYSTEM DESIGN

## User Roles & Permissions

### 1. Admin (Super User)
- Create developer accounts (frontend, backend, server)
- Assign developers to projects
- View all projects and tasks
- Manage users
- Dashboard shows: Total users, projects, tasks

### 2. Customer
- Create projects
- Create tasks for their projects
- View only their own projects/tasks
- Cannot see developers or assign them

### 3. Developers (Frontend, Backend, Server)
- **Cannot signup** - Admin creates their account
- Login with credentials given by admin
- See only tasks assigned to them
- Update task status only
- Cannot see other developers' tasks
- **Surprise element**: Don't know tasks until they login

## New Workflow

1. **Admin creates developer accounts**
   - Email: dev1@company.com
   - Password: generated by admin
   - Role: frontend/backend/server

2. **Customer creates project**
   - Project name, description
   - Status: "Waiting for developer assignment"

3. **Admin assigns developers to project**
   - Select project
   - Assign: 1 frontend, 1 backend, 1 server dev
   - Project status: "Active"

4. **Customer creates tasks**
   - Select project
   - Task title, description, category
   - Task auto-assigned to developer based on category

5. **Developer logs in**
   - Sees tasks assigned to them
   - Can update status: pending → in-progress → completed
   - Cannot see who created task or other details
